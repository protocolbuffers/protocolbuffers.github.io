## Changes in Go {#go}

### Updating Go Version Support Policy

Go Protobuf is updating its Go version support policy to support the two most
recent major releases of Go, aligning with the official [Go Release
Policy](https://go.dev/doc/devel/release#policy) and [Google Cloud Go's
supported versions
policy](https://cloud.google.com/go/getting-started/supported-go-versions).

Previously, Go Protobuf supported the two most recent Go releases plus one
additional prior release to align with Google Cloud Go's policy at the time. Now
that Google Cloud Go has updated its policy to support the two most recent Go
releases, Go Protobuf is aligning its support window accordingly.

Starting in the next release, the `go` language version in Go Protobuf's
`go.mod` file will be set to the oldest supported Go version (currently **Go
1.26**, dropping support for Go 1.25 and lower).

This was also announced in the [GitHub
issue](https://github.com/golang/protobuf/issues/1721).

### Adopting Quarterly Release Cadence and Version Support

Go Protobuf is adopting Protobuf's quarterly release cadence starting with the
`1.37.x` release, aligning its minor version numbering and release schedule with
`protoc`.

We have also added a Go section to the [Protobuf Version
Support](/support/version-support#go) page, which
documents Go Protobuf's current support policy and release history. Note that
unlike other Protobuf languages, Go Protobuf does not currently use release
branches and only the current release is supported; all releases, including
patch releases, are rollups from `HEAD` rather than true cherry-picks. We intend
to update this in the future to align with the rest of Protobuf.
